# Security

**This project is not covered by CircleCI's official security disclosure process
or support.** It is a CircleCI Labs project — see the Disclaimer in
[README.md](./README.md).

To report a vulnerability, follow
[CONTRIBUTING.md's Security disclosure section](./CONTRIBUTING.md#security-disclosure).
Please report privately rather than opening a public issue.

This file exists so GitHub's Security tab points somewhere useful; the substance
lives in CONTRIBUTING.md so there is one place to keep current.
